# ✈️ AI-Powered Travel Journal Assistant

An agentic travel management platform built using **React**, **FastAPI**, **MongoDB**, and **Docker**.

## 🌟 Key Features
- **Chat-Based AI Journal Assistant:** Interactive assistant helping with trip reflections and planning.
- **Journal Entry Management:** Full CRUD operations for creating, editing, and deleting travel logs with image attachments.
- **Expense Tracker:** Log daily travel expenditures by category and monitor budget totals.
- **Destination Planner:** Get custom itinerary highlights, daily budget estimates, and travel tips.
- **JWT Authentication:** Secure user registration and token-based authentication.
- **Dockerized Architecture:** Containerized multi-service orchestrations with Docker Compose.

## 🚀 Quick Start with Docker

```bash
# Clone repository
git clone https://github.com/YOUR_USERNAME/Travel-Journal-Application.git
cd Travel-Journal-Application

# Start services
docker-compose up -d --build
```

Access services at:
- **Frontend App:** `http://localhost`
- **FastAPI Backend Docs:** `http://localhost:8000/docs`
